School Update

A daily digest of school emails, filtered to what applies.

Active
Problem
Important notices are buried in long school newsletters, and dates are easy to miss.
Approach

A brief, action-first email with the right links and calendar buttons, and nothing at all on quiet days.

How I build

🧭

Code in charge

Ordinary code controls every step. The model is called only for specific jobs, like ranking, summarizing and extracting dates.

☁️

Runs itself

Everything runs on a schedule in the cloud. There's no server to maintain and no computer that has to stay on.

🔍

Trust, but verify

Model output is checked before it's used. For example, links come from the original email, not from the model.

🔒

Private by design

Credentials live in encrypted secrets, and personal details are kept out of the code and off this page.

Terms

LLM workflow
A pipeline where ordinary code controls every step (fetching, filtering, formatting, sending) and calls a large language model only for specific jobs such as ranking, summarizing or extracting dates. The model doesn't choose what happens next or use tools on its own, which keeps the result predictable and inexpensive. It differs from an agent, where the model itself directs the steps.
