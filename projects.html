School Update

Active

A daily digest of school emails, filtered to what applies.

Reads school emails from a Gmail label and has Claude keep only what applies to the family, sorted into things needing action, upcoming dates, and news. Adds links to sign-up forms and video meetings, plus one-click calendar buttons. It only sends when something is relevant.

GitHub Actions, every morning

  • Claude API
  • Gmail IMAP/SMTP
  • GitHub Actions
